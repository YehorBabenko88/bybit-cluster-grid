> **For agentic workers:** Use superpowers:executing-plans or scoped parallel tasks. Preserve the mandatory Python containment gate.

**Goal:** Obtain independent stock-CPython transport observations without importing or packaging Grid.

**Architecture:** Reuse only the existing native custody/token/Job/loader boundary; use a separately measured stock-only CPython closure and driver. Retain literal listeners/nonlisteners, arm bounded asynchronous accepts, sample only owned PID TCP rows, and capture nonblocking connect/readiness/SO_ERROR independently of policy acceptance.
