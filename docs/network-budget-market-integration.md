# Market-data network budget integration proposal

Status: INVENTORY PARTIAL; DESIGN ONLY; NOT RUNTIME QUALIFIED. Root approved the BudgetedTransport direction at plan level; exact stage-2 API and wire schema remain pending. No transport was run and no network request, probe, download, order, deployment, or infrastructure change was performed for this inventory. Root approval is required before existing-source changes or IPC extensions.

## Evidence and scope

Inspected Grid main `5765fac688e31c412ef78cebc4b201743dd62d78`, Strattester main `25eb939` and local unified-system source. The working BudgetAgent model was read separately in `mission-network-safety-1523/bybit-cluster-grid`; its uncommitted lifecycle work is not present on Grid main and is not imported here. Main Strattester uses **requests**, not a stdlib HTTP client. The raw pre-import admission layer being stdlib-only does not make its admitted HTTP dependency stdlib-only.

Inventory is partial because settings and persisted source URIs are dynamic, caller-injected sessions exist, dependency versions/transport internals were not exhaustively audited, and other modules, tools, installers and subprocesses can also originate network traffic. This document is no claim of machine-wide egress enforcement. No applicable AGENTS.md was found in the checked repository/ancestor locations.

## Strattester admitted DataFirst route

Grid `data_first_agent_worker.run_once` requires protected launcher admission before existing remote job claim → `data_first_process.DataFirstProcess` → fixed `-I -S -B` central bootstrap → unified-system `service_entry` / `service_bootstrap.run_protected_data_first` → `data_first_service.serve_research` → Strattester `grid_data_first_factory.build_scheduler` → `grid_data_first_worker.serve` → existing assigned execution. The standalone worker main deliberately fails closed when protected provisioning is absent. Existing INIT JSON cannot select a factory or grant.

The factory validates protected grant/workspace/current revision, pins the fixed strategy fingerprint and uses `PublicSession(gate)` with `BybitClient`. `PublicSession` uses `requests.Session`, `trust_env=False`, no auth, cleared cookies; permits fixed HTTPS public GET paths only: instruments, kline, mark/index/premium kline, open interest, account ratio. Requests must have stream=True, redirects=False, timeout=10. `BybitClient` reads `iter_content(65536)`, caps accumulated response at 8 MiB default (config ceiling 16 MiB), checks duplicate JSON keys, and closes response. Factory uses RetryPolicy(1,0,0), max concurrency 1 and existing scheduler rate/page/time limits. General client default is 5 attempts, timeout 30. General client construction and CLI/connectivity/smoke routes remain separate escape paths; gate-less clients and injected synthetic `json()` responses are not production admission.

The `before_request` callback proves current capability; it grants no per-read credit. `requests`/urllib3 streaming and automatic decoding can buffer/decompress before application `iter_content` yields. No proven wire-byte meter exists at this layer.

Current parent/child nonce-bound, sequence-checked closed IPC admits RENEW and CHECKPOINT (plus terminal DONE/ERROR). Preserve its strict exact-key/schema validation, source hashes, job/request hash binding, process lifetime bounds and cleanup. Proposed budget operations below are **not accepted by current protocol** and need coordinated Grid + Strattester + unified-system source-pin updates; do not loosen the current op allowlist generically.

## Existing HTTP failure behavior

Grid discovery retries 408/425/429/5xx; Retry-After is converted directly to float, without a finite upper bound. A 403 raised by `raise_for_status` is caught by the general aiohttp client-error retry branch and can be retried. Other Grid REST helpers raise HTTP errors without shared 403/429 feedback; archive probe returns 403/429 as unavailable, potentially misclassifying pressure/access denial as absent data. Archive worker failures re-enter existing retry queue.

Strattester prohibits redirects and treats 403 as terminal access error; 429/5xx and retCode 10006/10429 are retryable. Retry-After is capped by RetryPolicy.max_delay; its protected factory has one attempt. These local policies do not coordinate IP-wide cooldown. Every response must feed the shared authority-owned cooldown (including Retry-After/reset hints after strict bounded parsing). Budget denial/yield is distinct from remote absence and transport failure; it must not spend the archive job's retry-attempt allowance or mark a capability UNAVAILABLE.

## Proposed closed contract (root decision pending)

One explicit admitted transport object, passed at the real call sites. No global monkeypatch, environment JSON grants, fake source admission, extra scheduler, or SQLite authority. Policy allocation stays under existing Grid `service_leases` control-plane-leader fencing and `replicated_control_state` CAS. A local meter may persist only already-authorized debit/retirement state and cannot mint credit on boot, rollback, timeout, failover, or corrupt/unreadable journal.

1. OPEN: parent authenticates actor/node/module, immutable job/request hash, admitted source identity, operation, authority epoch/CAS version, exact endpoint/method/public path and bounded parameters. It durably charges each DNS/connect/TLS/HTTP/WS attempt before I/O. Redirects/proxies/auth/cookies/alternate destinations are rejected; no endpoint is accepted from child as new authority. Retry requires a fresh sequence/attempt admission.
2. READ request: <=65536 bytes, exact connection + next read sequence, at most one pending/outstanding read per connection. A grant binds unique read_id, epoch, actor, connection, request hash, source revision, amount, issue time and <=500 ms TTL. Issuance already reserves/debits policy capacity; denied or queued is not permission to read.
3. CONSUME: immediately before native read, validate current authority/admission, exact binding, strictly increasing monotonic deadline and one-shot state; durably persist consumed/debited state **before any network I/O**. The response's residual TTL must reach the transport and bound actual read/cancellation, rather than merely when the RPC was sent. Delayed first spend at/after expiry fails closed. A crash after durable debit burns capacity.
4. COMPLETE: only after the exact bounded native read is stopped and unable to continue receiving into unmetered buffers. Confirmed completion retires read sequence without refund, including EOF/short read/error. Unknown cancellation/stop, TTL expiry in-flight or mismatched receipt fences connection, keeps slot occupied until confirmed transport teardown, and cannot issue another READ. Replayed consume/complete never repeats I/O or credits.
5. CLOSE: confirm native transport teardown before releasing slot. Timeout is not proof of closure. Meter restart abandons unresolved reads/connections without granting replacement credit; authority recovery uses fresh fence and explicit reconciliation.

Proposed IPC names are BUDGET_OPEN, BUDGET_READ, BUDGET_CONSUME, BUDGET_COMPLETE, BUDGET_CLOSE and BUDGET_FEEDBACK, each with its own exact-key body and bounded values. These are semantics, not an approved wire schema. Parent derives actor/source/job/epoch; child cannot supply authority, priority, deadlines, renewed capacity or a replacement host. Parent ACK includes only the minimum connection/read receipt needed. Transport-owner cleanup must be verifiable across process death; source-admitted child code alone does not prove kernel/TLS buffering stopped.

Traffic charges need an explicit accounting domain: application payload, TLS plaintext, socket bytes and physical link bytes differ. A recv(64KiB) cap cannot account Ethernet/IP/TCP/TLS overhead or peer push already accepted by OS buffers. Keep bulk blocked until a reviewed implementation defines conservative overhead/buffering reserve and demonstrates the promised boundary. No claim of full wire-rate enforcement from application chunk sizes.

The existing model is LAB-only, not runtime permission. Observed model limits: READ <=64KiB, TTL 500ms, connection lifetime 5s renewable while confirmed, HTTP active <=4 / LOW <=2, WS <=3 on LS5, queued <=128 / LOW <=96 with per-node bounds, nominal HTTP attempts 5/s and WS 20/min. Its rates are not live admission settings. Root's current manual constraint is <=64KiB/s, one stream, metadata <=2 requests/s; no network operation is authorized by this document.

When LS5/authority is unavailable: pause bulk immediately, preserve queued progress, and permit only previously bounded live/monitor allowance with no fresh unbounded credit or bulk promotion. Model authority=false currently denies new OPEN; root must define whether preserving an already admitted live connection is sufficient or a separate finite pre-delegated emergency envelope is required. Do not invent local authority. No automatic DNS/router/Tailscale/firewall/ESET/Windows/Reolink repair.

* Root/control owner defines durable authority/CAS state, authenticated endpoint and admission envelope; root approves precise IPC schema and traffic accounting domain before any runtime hooks.

Proposed later reviewable adapter files: `grid/market_budget_transport.py`, `tests/test_market_budget_transport_contract.py`, and `tests/fixtures/network_budget_market_contract_v1.json`; names are reserved proposals, none created. Required scenarios: delayed first consume >=500ms; TTL expiry in-flight; replayed consume/complete; cross-actor/connection/source/job/epoch mismatch; unreadable/rollback meter; crash after debit; short/zero-byte reads with no refund; concurrent READ rejection; ignored Range + huge listing/JSON; redirect/auto-decompress/prefetch escape; 403/429 shared cooldown; per-node fairness; bulk pause on LS5 loss; bounded live/monitor with no new credits; reconnect storms and extra reachability probe denied. ## Wider escape paths requiring separate owners

Grid control heartbeat, storage/micro-event storage HTTP, ml_transport_client dataset transfer, agent_commands release downloads, deployment/self-update, Telegram and subprocess/imported tooling consume the same uplink. They are not covered by market wrappers. Strattester CLI/general client/connectivity/preflight/smoke are also not automatically protected by the admitted DataFirst factory. Inventorying these names is not source admission or authorization to run them. A safe integrated runtime must either assign each a bounded explicit adapter or leave it blocked; allowing an unwrapped fallback would invalidate aggregate-budget claims.

Connect/TLS attempts have a separate finite proposed 10-second deadline, with the connection slot held throughout and no unmetered response prefetch. The 500ms READ TTL begins only for the actual post-open read permission; it is not the whole TLS/dial deadline.
