## State and fence semantics
ASSIGN/supersede CAS current partition assignment and persistent counters, old/new worker reservations and node aggregate ledgers, storage hold references and worker/incarnation/drain/capacity. New assignment_revision and lease_epoch advance independently; assignment UUID/logical lease UUID are fresh. An old resource or storage debt is not silently freed by supersession. Native containment/proven release is required before reallocation.
RENEW_BEGIN atomically makes current grant RENEW_PENDING and advances grant_revision before any native TTL extension. Native session renewal alone cannot grant anything. RENEW_FINALIZE checks original pending intent/current tuple/session/current resources and makes ACTIVE at new grant revision; assignment_revision/lease_epoch remain fixed. Unknown intermediate stays non-authoritative and reconciles originalID. REVOKE makes current grant/binding terminal in a fenced transaction; native session destruction follows, not a substitute for committed invalidation.
Fencing token uses EXACT A3 V3 fields: assignment_id,assignment_revision,cluster_generation,grant_revision,leader_lock_index,lease_epoch,lease_id,node_id,owner_id,worker_incarnation_id. Each counter is separately issued; native indices are actual observations, not logical revision aliases. authority_session_binding uses exact leader_session_id,lease_session_id,lease_binding_revision. Issuing leader_lock_index is retained grant provenance; CURRENT coordinator leader/session/index checks are separate and must never reuse old issuing authority as current permission. A3 checkpoint authority_session_binding mapping versus issuing leader provenance needs explicit A3/A5 cross-field ACK before wiring. No automatic worker migration or LS5 failback follows from coordinator takeover. Publication checks both actual current coordinator lock and actual worker lease lock/binding plus current combined assignment native index; every stale tuple rejects.
REJOIN changes worker incarnation under native admission, preserving old reservations/uncertain debt; publication checks global worker incarnation so invalidation does not require rewriting an unbounded list of old assignments. Recovery generation changes via existing admitted authority process; old generation mutation rejects, historical roots/receipts remain immutable.
